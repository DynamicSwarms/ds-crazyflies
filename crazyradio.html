Crazyradio

A Crazyradio 2.0 must be used in order to use the full potential of this library. You can then follow the Getting started with the Crazyradio 2.0 guide.

Warning

USB permissions need to be set up in order to use the Crazyradio. Follow this guide to do so.

In order to achieve the bandwidth need for controlling multiple crazyflies, a radio with the Inline Mode must be used. The firmware is only compatible with the Crazyradio 2.0.

Flashing the firmware

The firmware is available as Crazyradio 2.0 firmware 5.3 or our fast-ramp firmware. Or you can download the firmware directly from bitcraze here (tested with version 5.3).

Bitcraze reports approximately 1200 packets per second with the standard inline mode firmware (see their article). Our fast-ramp firmware is faster and reaches approximately 1400 packets per second in our setup.

Plug in your Crazyradio2.0 with the button pressed, this will put the Crazyradio into bootloader mode. The Crazyradio will then show up as a mass storage device named Crazyradio. You can then drag and drop the crazyradio2.uf2 file onto the Crazyradio, which will automatically flash the modified firmware.

Compiling custom firmware

If you want to modify and compile the firmware yourself, you can follow the instructions below. Instructions on building and flashing can be found here. Be sure to have the Bitcraze Toolbelt installed, as it is required to build the firmware.

You are now ready to configure your Crazyflies.
